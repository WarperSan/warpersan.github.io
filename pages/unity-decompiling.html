Introduction

There are multiple reasons why you might want to decompile a game:

  • Extracting assets
  • Learning from others
  • Modding

In this article, I will go over how to decompile a game. Specifically, I will go over Unity games. Games made in Unreal Engine or any other engine can also be decompiled, but this method won't work for these engines.

How to obtain the game

Of course, you need the game itself in order to extract the project. The act of decompiling is already shady enough, you might not want to add piracy to your case.

How to extract the project

It is possible to go from an executable to a Unity project. If you want to do so, you need to follow theses steps:

  1. Download the Unity Editor

    2. Depending on the game, you need to install a different editor. A way to check what version you need is to install something like BepInEx. When you will run it, it should display the version of Unity required.

    You can always use a different version, but it is not recommended, due to potential bugs from the different versions.

  2. Download AssetRipper
  3. Launch the program
  4. Click File > Open File
  5. Select the executable
  6. Click Export > Export All Files
  7. Click Select Folder and select the destination folder
  8. Click Export Unity Project
  9. With Unity, open the folder ExportedProject

Just a head's up: this can take a while. Normally, only the first time should take as long (due to Unity downloading the missing libraries and setting assets up).

You can now see all the game's assets and continue your task. Note that decompiling only makes an approximate project. You won't have the same project as the creator(s).

Fixing the project

When opening the project for the first time, you might come across errors with the project. If Unity asked to open the project in Safe Mode, the project needs a bit of fixing. However, it is possible to fix the project in order to make it work. In this section, we will go over some errors and how to fix them.

Broken DLLs

If an issue like Unloading broken assembly 'AnyDLLFile', this assembly can cause crashes in the runtime comes up, here is how to fix it:

  1. Select the broken DLL in the Plugins folder
  2. In the Inspector, change the OS in the Editor Settings to Windows
  3. Click Apply

Black Scene

If you can't see anything in the Scene window, make sure the following files have their OS set to Windows:

  • Unity.RenderPipelines.Universal.Runtime.dll
  • Unity.RenderPipelines.Core.Runtime.dll

Broken Text

If there is text that displays as invisible, black or pink boxes, here is how to fix it:

  1. Located the shader that is linked to the material for the font
  2. Replace the shader's code with a clean one

    3. If the shader is TextMeshPro/Mobile/Distance Field, you can replace the code with this. You can also create a blank project, import the needed shaders and copy the code from there.

  3. Create a TMPro_Properties.cginc in the Shader folder

    4. You can use this file or find it in a blank project.
