BTD6 Boss Mods

I became a BTD6 modder on August 7th 2022. After releasing my first mod, I was brewing new mod ideas. In this community, you have 3 types of mods:

  • Tower mods (custom towers)
  • Map mods (custom maps)
  • Others (miscellaneous stuff)

But there were no mod for modded bosses (except from DatJaneDoe, but they were mostly private).

Boss Pack

On January 10, 2023, I released the "first" boss mod: Boss Pack. And it went as bad as expected. The first Youtuber who played it directly found several glitches. A sad moment, to be totally honest. Sadly, I have no picture for this era. The only things I could find are videos from Youtubers who played the mod. In this version, the user could only pick one boss per round.

Boss Integration

On June 26, 2023, the new API was released! This version of the API is way better than the previous one. Here is the same code, but from the new API:

It is WAY better, no doubt. Previously, the mod required a restart of the game if the player changes the selected bosses. Now, the player can change bosses without leaving the game. A side effect of this made it possible to have multiple bosses at once. Along with this, the mod gave an in-game interface that allowed the player to look at the stats of the bosses. Before, the player had to look on the README of the mod to find the details.
