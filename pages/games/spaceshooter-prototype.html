Space Shooter

This project was made as a project for school. Along with a colleague, we created a clone of Touhou.

The game randomly picks a wave from the built-in waves. There is also a boss fight.

This project is built on modular systems, allowing to create new enemies and new projectiles without having to heavily modify the systems. You can take a look at the source code here.

Controls

  • WASD to move
  • Left click or Space to shoot
  • Shift to move slower
