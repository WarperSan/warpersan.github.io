Story

This isn't a personal project. As a final project for school, we had to make the game Boulder Dash in C#. We had (probably) around 3-4 weeks to do it. If you want to look at the code or/and try the game, you can find the source code here. Note that the comments are written in French my native language. Before posting the code on GitHub, I translated the few menus in order to allow anyone to try it.

I overkilled the project and made a lot more than requested. For example, I made an entire level editor. For context, people in the class just learned to code and I had a few years of experience beforehand.

Sadly, I don't have many pictures of the project. In fact, the previous images were taken for this. This is still a piece of my learning of C# and coding in general.
